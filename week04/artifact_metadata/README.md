# Week 04 retained artifact metadata

This directory is a Git-sized copy of the CSV/JSON/README evidence from the generated Week 04 constrained-GASF datasets.

- `minmax01/` records the analytically invertible `[0,1]` representation, split membership, alignment checks, delta-consistency checks, and normalization summaries.
- `neg11/` records the `[-1,1]` representation, split membership, distribution analysis, sign-ambiguity/invertibility metrics, and normalization summaries.

The original generated directories also contain thousands of PNG/NumPy samples and multi-gigabyte training artifacts. Those binary outputs remain outside Git. Their locations and scientific status are documented in `experiment_inventory.md`, `results_summary.md`, and `figure_inventory.md`.

Files in this directory are copied from:

- `week04/data_constrained_gasf_dxdy_start/`
- `week04/data_constrained_gasf_dxdy_start_neg11/`

They should be refreshed if either generated dataset is rebuilt.
